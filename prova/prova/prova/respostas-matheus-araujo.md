Respostas prova back-end 10/04
1- O git init cria um repositório do zero, já o git clone ja vem o repositório pronto.
2- O git status mostra o estado atual do seu repositório.
3- Serve para adicionar todas as alterações que vão entrar no commit.
4- O git fetch baixa atualizações remotas sem mexer no seu código atual, já o git pull aplica as atualizações no seu projeto.
5- Branch é uma linha de desenvolvimento separada dentro do seu projeto, usada para desenvolver sem quebrar o projeto principal.
6- É quando você solicita as alterações da sua branch sejam revisadas e integradas em outra branch.
7- Branch de origem vai realizar as alterações, já a branch de destino vai receber as alterações.
8- O git não consegue saber qual a correta.
9- Serve para dizer quais arquivos você não precisa usar.
10- Serve como auxiliar do seu projeto, serve como porta de entrada do seu projeto.
